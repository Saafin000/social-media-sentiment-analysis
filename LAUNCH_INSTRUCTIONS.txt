================================================================================
TROUBLESHOOTING
================================================================================

Q: Dashboard won't open
A: Check if port 8501 is in use. Use: python -m streamlit run app/streamlit_app.py --server.port 8502

Q: Model predictions not loading
A: Ensure model files exist in models/ directory:
   - sentiment_model.pkl
   - vectorizer.pkl

Q: Batch upload not working
A: CSV must have a 'text' column with the text data to analyze

Q: Dashboard is slow
A: Clear cache by pressing C in the dashboard, or restart the app
